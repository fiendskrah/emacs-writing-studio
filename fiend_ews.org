* Introduction

This document is the source of my Emacs configuration, `fiendmacs`. Tangling it writes =init.el=; the elisp blocks are the configuration and the prose describes what each package does here. The base config is Emacs Writing Studio (EWS) by Peter Prevos (=github.com/pprevos/emacs-writing-studio=), extended with additional tools for literature management, research notes and deadline-driven task tracking.

The chapters follow load order. Package management and the EWS helpers come first, then the control layer (Evil, Hydra, general.el), then the interface, then Org, the agenda and the personal knowledge base, and finally the file, tool, writing and publication packages. A block may rely on anything above it, so new code goes below its dependencies.

Editing happens in this file only. =SPC x r= tangles it and restarts Emacs. Settings made through the customisation interface land in =custom.el=.

* Foundations

** Startup

Garbage collection is relaxed and file-name handlers are suspended while Emacs starts, then restored once startup finishes. The startup screen is suppressed in favour of the dashboard, and native fullscreen is off on macOS because it breaks tooltips.

#+begin_src elisp
(defvar fiend--file-name-handler-alist file-name-handler-alist)
(setq gc-cons-threshold (* 128 1024 1024)
      gc-cons-percentage 0.6
      file-name-handler-alist nil)

(add-hook 'emacs-startup-hook
          (lambda ()
            (setq gc-cons-threshold (* 16 1024 1024)
                  gc-cons-percentage 0.1
                  file-name-handler-alist fiend--file-name-handler-alist)))

(setq inhibit-startup-message t)
(setq ns-use-native-fullscreen nil)

(when (< emacs-major-version 29)
  (error "Emacs Writing Studio requires Emacs version 29 or later"))
#+end_src

** Package management

Packages come from MELPA first, then GNU ELPA and NonGNU ELPA. =use-package= declares each package, and =use-package-always-ensure= installs anything missing, so a block that names a package is enough to obtain it. Warnings below emergency level are silenced. Packages that are built in or deliberately absent set =:ensure nil=.

(package-initialize)

(unless package-archive-contents

(unless (package-installed-p 'use-package)

* Control

Modal editing is the organising principle of the interface. Evil provides Vim-style states, general.el adds a =SPC= leader in Normal, Visual, Motion and Emacs states, and Hydra groups repeated commands behind that leader. Evil bindings apply wherever a mode allows them. Modes that ship their own keymaps (Dired, the agenda, PDF view, the dashboard, Org's =RET=) need explicit overrides, which live next to the package that creates the conflict and are noted in each section.

** Evil

Evil emulates Vim's modal editing. Its own keybinding layer is disabled in favour of Evil Collection, which supplies Evil bindings for most modes. In Insert state =C-g= returns to Normal state, =C-h= deletes backwards, and =j= and =k= move by visual line in Motion state so wrapped prose behaves. The Messages and dashboard buffers start in Normal state.

#+begin_src elisp
(use-package evil
  :ensure t
  :init
  (setq evil-want-keybinding nil)
  (setq evil-want-integration t)
  :config
  (evil-mode 1)
  (evil-define-key 'insert evil-insert-state-map (kbd "C-g") 'evil-normal-state)
  (evil-define-key 'insert evil-insert-state-map (kbd "C-h") 'evil-delete-backward-char-and-join)
  (evil-set-initial-state 'messages-buffer-mode 'normal)
  (evil-global-set-key 'motion "j" 'evil-next-visual-line)
  (evil-global-set-key 'motion "k" 'evil-previous-visual-line)
  (evil-set-initial-state 'messages-buffer-mode 'normal)
  (evil-set-initial-state 'dashboard-mode 'normal))
#+end_src

** Doom Modeline

Doom Modeline replaces the stock mode line. Its icons come from Nerd Icons, whose font is installed once with =nerd-icons-install-fonts=. The file name is shown from the project root (=truncate-with-project=). Files in the PKB are shown by title alone: =fiend/mode-line-slug= drops the Denote timestamp, optional signature and =__keywords= from the displayed name, so =20260109T154328--home-server__homeserver_hub.org= reads =home-server.org=. Only the display changes, never the file. Names that are not Denote names, or have no title, pass through unchanged. Doom Modeline calls the function through =doom-modeline-buffer-file-name-function=. The bar also shows a word count in Org buffers (the selection's count while text is highlighted), the total line count beside the current line, and the clock from =display-time-mode=.

#+begin_src elisp
(defconst fiend/mode-line-denote-regexp
  "\\`[0-9]\\{8\\}T[0-9]\\{6\\}\\(?:==[^-_.]*\\)?--\\([^_.]+\\)\\(?:__[^.]*\\)?\\(\\..*\\)?\\'")

(defun fiend/mode-line-slug (path)
  (let ((name (file-name-nondirectory path)))
    (if (string-match fiend/mode-line-denote-regexp name)
        (concat (file-name-directory path)
                (match-string 1 name)
                (or (match-string 2 name) ""))
      path)))

(use-package doom-modeline
  :hook (after-init . doom-modeline-mode)
  :custom
  (doom-modeline-buffer-file-name-style 'truncate-with-project)
  (doom-modeline-buffer-file-name-function #'fiend/mode-line-slug)
  (doom-modeline-height 28)
  (doom-modeline-enable-word-count t)
  (doom-modeline-total-line-number t))

(display-time-mode 1)
#+end_src

** Fonts

Faces use families bundled with macOS: Menlo for code and Avenir Next for prose. Only families are set, never heights, so sizes follow the frame. =fiend/set-font= (=SPC t f=) switches the prose or code family for the rest of the session and re-toggles Mixed Pitch so open buffers pick it up.

#+begin_src elisp
(set-face-attribute 'default nil :family "Menlo")
(set-face-attribute 'fixed-pitch nil :family "Menlo")
(set-face-attribute 'variable-pitch nil :family "Avenir Next")

(defun fiend/set-font (faces family)
  "Set FAMILY on FACES globally (prose = variable-pitch, code = default)."
  (interactive
   (let ((target (completing-read "Font for: " '("prose" "code") nil t)))
     (list (if (string= target "prose") '(variable-pitch) '(default fixed-pitch))
           (completing-read (format "%s font: " target)
                            (seq-remove (lambda (f) (string-prefix-p "." f))
                                        (delete-dups (sort (font-family-list) #'string<)))
                            nil t))))
  (dolist (face faces)
    (set-face-attribute face nil :family family))
  (dolist (buf (buffer-list))
    (with-current-buffer buf
      (when (bound-and-true-p mixed-pitch-mode)
        (mixed-pitch-mode -1)
        (mixed-pitch-mode 1)))))
#+end_src

** Capture and task keywords

Capture is the entry point for the task workflow. Task capture templates file a tagged TODO into the inbox under "Captured task pile", with the tag naming the area (dissertation, service, life, teaching, tool and so on) so the item lands in the right agenda group before it is processed. Note capture templates create a Denote note in the PKB directly and skip the inbox. The weekly focus template prompts for a Monday and files a heading with an inactive Monday-to-Sunday range under "Weekly focus", with TODO children that the week agenda lists once at the top.

Two independent keyword sequences define task state. =TASK=, =TODO=, =NEXT= and =IDEA= lead to =DONE=; =HOLD=, =WAITING= and =DEADLINE= lead to =CANCELLED=. Completion is timestamped with a =CLOSED:= line. Tags are declared with fast keys in three groups: five parking and topic tags, a priority group (=p1= to =p3=, with =p3= meaning parked) and a stage group (=ideation=, =paper=, =relic=). The priority and stage groups are mutually exclusive, so a note carries at most one of each. All other tags are free-form. The base agenda files are fixed here; the PKB directory is added to them in the agenda chapter.

* Agenda

The agenda is the primary work-management surface. It covers dissertation work, coursework and general obligations, and its file list is rebuilt on every call rather than once at startup.

** Agenda files

The agenda files are the fixed base list plus every real note in the PKB directory. ** PKB tools

Local helpers in =fiend_tools/= and below move captured items into the PKB. =SPC p p= jumps to a note by title, =SPC p t= narrows by tag through the picker in =my-pkb-picker=, and =SPC p g= searches text.

=SPC p f= cuts the subtree at point and files it into an existing note as a new top-level heading tagged =:new:=, which marks it as not yet triaged. =SPC p n= cuts the subtree, uses its heading as the title and creates a new note in =pkb/=, prompting for keywords and writing them to both the filename and the front matter. =SPC p v= transcribes a video to an =.srt= file in =pkb/refs/= with Whisper in a conda environment, asynchronously, so the transcript becomes searchable. =M-x fiend/pkb-promote= runs =promote-idea.py= on the current note: without a prefix argument it prints the plan and the reference checks and writes nothing; with =C-u= it copies the note and everything it touches into a new project folder under =works/=.

Plain =org-refile= (=C-c C-w=) targets the top level of PKB notes only, shows headline text without paths, and inserts new items first in =pkb/= files. The refile targets deliberately exclude =bib_notes/=.

#+begin_src elisp
(add-to-list 'load-path (expand-file-name "fiend_tools" user-emacs-directory))
(require 'my-pkb-picker)

(setq org-refile-targets
      '((fiend/pkb-org-files :maxlevel . 1)))

(setq org-refile-use-outline-path nil
      org-outline-path-complete-in-steps nil
      org-refile-allow-creating-parent-nodes 'confirm)

(defun fiend/pkb-candidates ()
  "Alist of (title . file) for every pkb note."
  (mapcar (lambda (f) (cons (my/pkb--title-for-display f) f))
          (my/pkb--all-files)))

(defun fiend/pkb-pick-by-title ()
  "Jump straight to a pkb note by title (SPC p p). Complements
`my/pkb-pick-by-tag' (SPC p t), which narrows by tag instead."
  (interactive)
  (let* ((candidates (fiend/pkb-candidates))
         (choice (completing-read "PKB note: " candidates nil t)))
    (find-file (cdr (assoc choice candidates)))))

(defun fiend/pkb-refile-to-top ()
  "Cut the subtree at point and file it into an existing pkb note as a
new H1 at the very top of the file, tagged :new:. Meant to be triaged into
the note's real structure during a later review pass, then have the :new:
tag dropped."
  (interactive)
  (unless (org-at-heading-p) (org-back-to-heading t))
  (let* ((candidates (fiend/pkb-candidates))
         (choice (completing-read "File into pkb note: " candidates nil t))
         (target-file (cdr (assoc choice candidates))))
    (org-cut-subtree)
    (with-current-buffer (find-file-noselect target-file)
      (org-with-wide-buffer
       (goto-char (point-min))
       (when (re-search-forward "^\\* " nil t)
         (beginning-of-line))
       (org-paste-subtree 1)
       (org-back-to-heading t)
       (org-set-tags (delete-dups (cons "new" (org-get-tags nil t)))))
      (save-buffer))))

(setq org-reverse-note-order '(("/pkb/" . t)))

(defun fiend/pkb-transcribe-video (video)
  "Transcribe VIDEO with whisper (media-tools conda env) into an .srt
transcript in pkb/refs/, timestamped and searchable via
`consult-notes-search-in-all-notes' since refs/ sits inside
denote-directory. Runs async - transcription of a lecture-length video
takes minutes, and shouldn't block Emacs while it runs."
  (interactive (list (read-file-name "Video file: " "~/acropolis/media/")))
  (let* ((outdir (expand-file-name "pkb/refs/" fiend/denote-lib))
         (default-directory outdir))
    (async-shell-command
     (format "conda run -n media-tools whisper %s --output_dir %s --output_format srt"
             (shell-quote-argument (expand-file-name video))
             (shell-quote-argument outdir))
     (format "*whisper-transcribe-%s*" (file-name-base video)))))

(defun fiend/pkb-promote (slug &optional execute)
  "Run promote-idea.py on the current note for project SLUG.
Without a prefix argument print the plan and checks only; with one, write the folder."
  (interactive (list (read-string "Project slug: ") current-prefix-arg))
  (compile (string-join
            (delq nil (list "python3"
                            (shell-quote-argument (expand-file-name "fiend_tools/promote-idea.py" user-emacs-directory))
                            (shell-quote-argument (buffer-file-name))
                            (shell-quote-argument slug)
                            "--lib" (shell-quote-argument (expand-file-name fiend/denote-lib))
                            (and execute "--execute")))
            " ")))

(defun fiend/pkb-extract-subtree-to-note ()
  "Extract the org subtree at point into a new Denote note in pkb/.
The heading text becomes the title; everything else is inserted as-is."
  (interactive)
  (unless (org-at-heading-p) (org-back-to-heading t))
  (let ((title (nth 4 (org-heading-components)))
        (keywords (denote-keywords-prompt)))
    (org-cut-subtree)
    (let ((body (substring-no-properties (current-kill 0)))
          (denote-directory (expand-file-name "pkb/" (denote-directory))))
      (denote title keywords)
      (goto-char (point-max))
      (insert "\n"
              (with-temp-buffer
                (insert body)
                (goto-char (point-min))
                (when (looking-at "^\\*+ .*\n")
                  (delete-region (point) (match-end 0)))
                (buffer-string)))
      (save-buffer))))
#+end_src
